# Ananda Sangha Event Desk

Windows x64 desktop application distribution.

## Current version

**v118**

This repository distributes the Windows package in parts because GitHub repository files have a size limit.

## Install

1. Download all six files named `Ananda_Sangha_Event_Desk_Installer_v118.exe.part00` through `.part05`.
2. Download `JOIN_INSTALLER_v118.bat` into the same folder.
3. Double-click `JOIN_INSTALLER_v118.bat`.
4. It creates `Ananda_Sangha_Event_Desk_Setup.exe`.
5. Double-click the created setup file.

Do not open a `.part` file directly. All six parts must be present in the same folder.

The application is intended for 64-bit Windows and includes its own Chromium runtime; Chrome or Edge is not required.

## Important

The installer creates the application and Desktop shortcut. Keep the installed application folder together; do not move only the EXE out of its folder.
